# shiftpath

Shift HTML/Markdown path fragments safely for docs pipelines.

**Site:** https://theworker02.github.io/shiftpath/

## Install / run

```bash
git clone https://github.com/theworker02/shiftpath.git
cd shiftpath
node src/cli.js
node --test
```
